# AI Mode — Research

## 목적

아직 구현 방법을 결정하지 않은 문제를 조사한다.

## AI의 역할

AI는 자료 조사자이자 대안 분석자 역할을 한다.

## LIMO 자료 우선순위

1. 교수님 제공 WeGo 교재
2. AgileX / WeGo 공식 자료
3. ROS 2 공식 문서
4. Navigation2 공식 문서
5. SLAM Toolbox 공식 문서
6. 커뮤니티 자료

## 권장 프롬프트

```text
[조사]

현재 <프로젝트/기능>에서 <목표>를 구현하려고 한다.

아직 구현 방법을 결정하지 않았다.
먼저 관련 자료를 조사하고 가능한 방법을 비교해줘.

각 방법에 대해:
- 동작 원리
- 필요한 구성요소
- 장점
- 단점
- 현재 프로젝트 적용 조건
- 예상되는 문제

를 설명해줘.

자료에서 확인된 내용과 AI의 분석/제안을 구분해줘.
아직 코드를 작성하지 마.
```

## 완료 조건

구현 가능한 대안과 각각의 차이를 이해하고 구현 방법을 선택할 수 있으면 설계 단계로 넘어간다.

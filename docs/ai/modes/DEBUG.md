# AI Mode — Debug

## 목적

실행 중 발생한 오류의 원인을 찾아 최소한으로 수정한다.

## 핵심 원칙

실제 오류 로그를 먼저 본다. 원인이 확인되기 전에 프로젝트를 크게 변경하지 않는다.

## 권장 프롬프트

```text
[디버깅]

현재 작업:
<무엇을 실행했는가>

실행 명령:
<명령>

실제 오류 로그:
<원본 로그>

먼저 로그에서 확인되는 사실과 추측을 구분해줘.

그 다음:
1. 가능한 원인
2. 우선 확인할 원인
3. 확인 명령어
4. 필요한 수정
5. 수정 후 검증 방법

순서로 진행해줘.

원인이 확인되기 전에는 코드를 크게 변경하지 마.
```

## 분석 순서

```text
증상
→ 로그
→ 현재 상태
→ 원인 후보
→ 확인
→ 최소 수정
→ Build
→ Run
→ Test
```

## 완료 조건

오류가 해결되고 정상 동작이 검증되었으며 원인과 해결 과정이 기록되어야 한다.

# AI Mode — Learning

## 목적

모르는 개념이나 기술을 이해한다.

## AI의 역할

AI는 교사 역할을 한다. 코드를 바로 제공하기보다 개념, 구조, 데이터 흐름을 먼저 설명한다.

## 권장 프롬프트

```text
[학습]

나는 <기술/개념>을 배우는 중이다.

먼저 개념을 쉽게 설명해줘.
그 다음 현재 프로젝트에서 이 개념이 어디에 사용되는지 설명해줘.

다음 내용을 포함해줘.
1. 무엇인가?
2. 왜 필요한가?
3. 어떻게 동작하는가?
4. 관련된 ROS 2 구성요소는 무엇인가?
5. 간단한 예시는 무엇인가?
6. 현재 프로젝트에서는 어떻게 연결되는가?

아직 코드를 작성하지 말고 개념과 데이터 흐름 중심으로 설명해줘.
```

## 좋은 질문

- 왜 필요한가?
- 다른 방법은 없는가?
- Topic / Service / Action과 무엇이 다른가?
- 실제 LIMO에서는 어디에 사용되는가?
- 이 코드를 이해하려면 어떤 개념을 먼저 알아야 하는가?
